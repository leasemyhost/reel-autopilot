# Privacy Policy - JKG Reel Autopilot

Last updated: 23 November 2026

JKG Reel Autopilot is a private tool used only by Jayant Srivastava (Jayant Ke Guides, LMH Connect) to upload
his own short videos to his own YouTube channel and Instagram accounts.

- **Data accessed:** only the permission to upload videos (YouTube scope `youtube.upload`) to the owner's own channel.
  The tool does not read, edit or delete existing videos, comments, subscribers or any other channel data.
- **Data stored:** an access/refresh token stored as an encrypted GitHub Actions secret. No personal data of
  viewers or any other user is collected, stored or shared.
- **Sharing:** no data is sold or shared with third parties.
- **Revoking access:** the owner can revoke access any time at https://myaccount.google.com/permissions.
- **Contact:** examtadka92@gmail.com

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the
Limited Use requirements.
